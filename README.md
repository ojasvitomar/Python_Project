College Student Expense Tracker

Project Overview
The College Student Expense Tracker is a beginner-friendly, menu-driven Python application designed to help college students record, organize, and analyze their daily expenses.

Objectives
1. Record individual expenses with a name, amount, and category.
2. Calculate total spending.
3. Analyze spending category-wise.
4. Identify the highest and lowest expenses.
5. Search for a particular expense.
6. Set a monthly budget and check spending against it.

Features
1. Add Expense
2. View All Expenses
3. View Total Spending
4. Category-wise Spending
5. Find Highest Expense
6. Find Lowest Expense
7. Search Expense
8. Set Monthly Budget
9. Check Budget Status
10. Display Expense Categories
11. Exit

Concepts Used
1. Variables and data types
2. Arithmetic, comparison and logical operators
3. Conditional statements
4. for and while loops
5. Functions
6. Lists
7. Dictionaries
8. Sets
9. String operations
10. Basic searching and comparison algorithms

Requirements
VS Code or any Python-compatible IDE

How to Run
Open the project folder in VS Code.
Open main.py.
Run:
python main.py
